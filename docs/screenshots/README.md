# Screenshots

## AI Sentiment Intelligence — Application Screenshots

This directory contains screenshots of the Streamlit web application.

> **Note:** Screenshots must be captured manually by launching the application and taking browser screenshots.
> They cannot be auto-generated by scripts. The application must be running at http://localhost:8501.

---

## How to Capture Screenshots

1. Launch the application:
   ```bash
   streamlit run app/app.py
   ```

2. Open your browser at http://localhost:8501

3. Navigate to each tab and capture full-page screenshots.

4. Save them in this directory using the filenames listed below.

## Screenshot Tips

- Use browser zoom at 100% for consistent screenshots
- Capture the full browser window including the sidebar
- Ensure the sidebar is expanded to show all 7 stage status indicators
- For prediction screenshots, use representative example sentences:
  - **Positive**: "This product is absolutely amazing and exceeded all my expectations!"
  - **Negative**: "Terrible experience, completely disappointed with the quality."
  - **Neutral**: "The package arrived on Tuesday. It contains three items."
